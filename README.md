# Data Analysis Practice – Python Learning Portfolio

## 📊 Project Overview

This repository documents my hands-on learning in **Python for Data Analytics** through Jupyter notebooks and topic-specific documentation. The goal is to develop practical programming skills for working with data, progressing from numerical computing to data manipulation, cleaning, and visualisation.

The repository complements my [Excel](https://github.com/Alirazasadaq6/excel-practice) and [Power BI](https://github.com/Alirazasadaq6/Power-BI-Practice) portfolios. Each topic README states whether it uses sample values or a real dataset. The current NumPy exercises use small arrays defined in the notebook, with no external dataset.

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Alirazasadaq6/data-analysis-practice.git
   cd data-analysis-practice
   ```

2. Install the current notebook's dependencies:

   ```bash
   python -m pip install "numpy>=2.0" notebook
   ```

3. Launch Jupyter with `jupyter notebook`, then open `01-numpy/01_numpy_basics.ipynb` and run its cells in order.
